n9 / FreeLinX Operating System

Introduction

n9 / FreeLinX is an independent x86_64 Linux distribution. It pairs the Linux 6.18 LTS kernel with a NetBSD 10.1 userland, musl libc, and an LLVM/Clang toolchain; the base system contains no GNU runtime or GNU core utilities. runit supervises services, mdevd handles devices, and the custom xpkg package manager installs from Ed25519-signed indexes with SHA-256 verification and atomic updates. It boots on BIOS and UEFI systems.
